# STILL — The Last Second

A new hero direction developed independently from the rejected armored prototypes.

## Files

- `LastSecond.blend`: actual editable Blender model, organized into HERO and STUDIO collections. Smooth mesh surfaces, subdivision modifiers, curve-based hair/detail, procedural materials and studio cameras/lights.
- `hero-blender.png`, `portrait-blender.png`, `back-blender.png`: actual Cycles renders of that model.
- `concept-reference.png`: AI-generated concept art defining the visual target. It is not a Blender render and is not evidence of the model's level of detail.
- `../../../Tools/create_last_second.py`: reproducible Blender model construction and rendering script.

## Character identity

A time-worn duelist whose chronometer gauntlet holds the last seconds of a ruined world. The face is visible; the silhouette comes from a swept collar, asymmetric ivory mantle, crimson scarf, tailored coat tails and a long narrow sword. Antique brass, midnight teal wool, oxblood lining and restrained teal enamel establish the initial palette.

Art direction for later work: worn precision mechanisms and engraved brass for time-related elements, human fabric and leather for the protagonist, stronger distortion and damaged mechanisms for enemies, monumental stone and interrupted clock architecture for environments. These are directions to develop after the hero's design is accepted.

## Current scope

This is an editable character design study, not a finished production model. The generated concept has substantially richer anatomy, hair, fabric wear and ornamentation than the current Blender study. Matching that target still requires dedicated sculpting, garment refinement and texture authoring. This study has no animation rig, production UV layout, baked texture set or optimized game topology. It has not replaced the Unity player and is not in the previous Windows build.

The previous Keeper and block-shaped characters remain available as archived iterations. No claim is made that increasing polygon count alone achieves the desired hero quality.
